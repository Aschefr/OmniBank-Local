La page **Catégories** vous permet d'organiser et de personnaliser l'arborescence comptable de vos revenus et dépenses dans OmniBank Local.

## 🛠️ Composants & Fonctionnalités

### 1. Arborescence Hiérarchique (Parent / Enfant)
L'organisation financière repose sur une structure à deux niveaux :
- **Catégorie Parent** : Grand poste de dépense ou de revenu (ex: *Alimentation*, *Logement*, *Revenus du travail*).
- **Sous-catégorie** : Poste détaillé (ex: *Supermarché*, *Boulangerie*, *Loyer*, *Charges*, *Salaire net*).

### 2. Personnalisation Visuelle
Pour chaque catégorie ou sous-catégorie, vous pouvez personnaliser :
- **Le Nom** (traduisible ou personnalisé).
- **L'Icône** : Large choix d'icônes vectorielles représentatives (caddie, voiture, maison, ampoule, restaurant, etc.).
- **La Couleur** : Palette de couleurs tailormade pour repérer immédiatement vos dépenses dans les graphiques.
- **Le Type** : *Revenu* (Crédit) ou *Dépense* (Débit).

### 3. Protection & Fusion de Catégories
- **Suppression sécurisée** : Si vous tentez de supprimer une catégorie contenant déjà des transactions, OmniBank vous propose de les réaffecter à une autre catégorie de votre choix.
- **Fusion** : Regroupez deux catégories similaires sans perdre l'historique comptable.
