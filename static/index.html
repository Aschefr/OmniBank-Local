👤 Paramètres du profil

💡 Un profil maître est un espace de comptes indépendant. Il possède sa propre base de données locale, ses catégories et ses pièces jointes isolées sur cet appareil.
Sélectionnez une icône, tapez un emoji, ou utilisez le bouton 😊 (ou le raccourci Win + . / Cmd + Ctrl + Espace).
Protection par code PIN
Gestion du code PIN de sécurité
Ce code PIN sera demandé lors de chaque ouverture ou basculement vers ce profil.

🔒 Code PIN de protection

Ce que protège le PIN : sans lui, l'application et le serveur refusent l'accès aux données de ce profil, sur tous les appareils. Après 5 erreurs, il faut attendre 5 minutes.
Code de récupération : affiché une seule fois à chaque nouveau PIN. Notez-le : il permet de réinitialiser un PIN oublié et de restaurer ce profil sur une autre machine.
Limite : le PIN protège l'accès par l'application, pas les fichiers sur le disque du serveur.
